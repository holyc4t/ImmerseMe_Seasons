# ImmerseMe: Seasons Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build `ImmerseMe_Seasons`, a standalone WoW Forever addon that shows the season on the minimap rim (tint, frost layer, year-arc with festival notches) with a rich hover tooltip.

**Architecture:** Five Lua files loaded in order:
- `Data.lua`: Seasons wording and tint tables.
- `Almanac.lua`: copy-ready calendar maths with its own festival data.
- `Climate.lua`: a verbatim copy of Weather's temperature model.
- `Core.lua`: pure state and tooltip model, no frames.
- `UI.lua`: frames, events, slash commands.

All logic is deterministic from zone, realm time and the real date, and is tested outside the game with standalone Lua.

**Tech Stack:** Lua 5.1 (WoW Forever, `## Interface: 16001`). Tests run with `lua tests/run.lua` (Lua at `C:\Users\serge\AppData\Local\Programs\Lua\bin\lua`). Textures come from Python 3 with no dependencies, generating 32-bit TGA files.

**Spec:** `docs/superpowers/specs/2026-11-16-seasons-design.md` (workspace root). Read it before any task.

## Review Focus

1. **Year wrap.** On 30 December, Winter Veil (15 Dec – 2 Jan) is active. On 1 January it is still active and the arc dot sits at the left end. "Next festival" on 31 December must look into next year's festivals. → Task 3 test `upcoming wraps the year`.
2. **Leap years.** On 29 February and on 31 December of a leap year (day 366), the season, arc fraction (≤ 1) and sun maths must not error. → Task 2 test `leap day and day 366`.
3. **No known zone yet.** Logging in straight into an instance or an unknown zone with no last outdoor zone gives the default climate, no error and no frost inside the instance. → Task 5 test `instance with no last zone`.
4. **Frost on reload.** A `/reload` at a temperature between 1 and 2°C must give the same frost state as never reloading. A fresh state (no previous frost) replays the last 60 minutes of the plain model. → Task 6 test `fresh state equals continuous state`.
5. **Minimap input.** The hover target must not swallow clicks, pings or mouse-wheel zoom on the map interior or the stock minimap buttons. → Task 9 manual check (in-game only).

### Task 3: Moveable feasts and festivals

**Files:** Modify `Almanac.lua`; test in `tests/almanac_spec.lua`.

**Interfaces:**
- Produces: `A.Easter(year) -> month, day` (anonymous Gregorian algorithm).
- Produces: `A.LunarNewYear(year) -> month, day`. This is the second mean new moon after 21 December of `year − 1`, using `A.NEW_MOON_EPOCH = 947182440` and `A.SYNODIC = 29.530588` (the same constants as Weather). The date is taken with `date("*t", t)`.
- Produces: the `A.FESTIVALS` list. Each entry is `{ key, name, notch = bool, start = fn(year) -> month, day, days = integer }`:

|---|---|---|---|---|

| `hallow` | Hallow's End | true | 10/18 | 15 |
| `veil` | Feast of Winter Veil | true | 12/15 | 19 |
| `darkmoon` | Darkmoon Faire | false | first Sunday of every month | 7 |

  Darkmoon gets one window per month. Add a comment saying the dates are Blizzard's usual windows and must be checked against current Classic Era behaviour.
- Produces: `A.Upcoming(t, horizonDays) -> list`. Each item is `{ key, name, notch, active = bool, days = integer }`, where `days` is the number of days until the start (0 if active). - Produces: `A.NotchFractions(year) -> list`. Each item is `{ key, frac }` for `notch = true` festivals, where `frac` is the `YearFraction` of the start date.

### Task 6: Frost with hysteresis, and forecast

**Files:** Modify `Core.lua` and `Data.lua`; test in `tests/core_spec.lua`.

**Interfaces:**
- Produces in `Data.lua`:
  - `ns.FROST_ON = 1`, `ns.FROST_OFF = 2`, `ns.FROST_ALLDAY = -4`.

- Produces: `ns.FrostStep(temp, hour, season, rise, wasOn) -> bool`. Frost is on when:
  - in the morning window and either `temp < FROST_ON`, or `wasOn and temp <= FROST_OFF`; or

- Produces: `ns.Frost(zone, t, hour, opts, prevOn) -> bool`. When `prevOn == nil` it replays seven steps from `t − 3600` to `t` in 10-minute steps of `OutdoorTemp`. - Produces: `ns.FrostForecast(zone, t, hour) -> { now = bool, liftsAt = hour|nil, tomorrow = bool }`. It uses the plain model only (no `opts.weather`), stepping forward in 30-minute steps up to 24h, like Weather's `Outlook`.
