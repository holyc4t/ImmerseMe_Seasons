# Sun path Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the rim's year-arc with a sun path under the minimap: a painted arch, a painted sun
riding it by day of the year, festival notches, and a hover target for the season tooltip.

**Architecture:** `ns.SunHeight(f)` in `Core.lua` is the curve (pure, tested). `UI.lua` gets a small
mouse-enabled frame anchored under the minimap holding the arch texture, the sun and the notches;
its geometry constants match `tools/make_textures.py` (tested like the ring geometry).

**Tech Stack:** Lua 5.1 (classic-era API), Python 3 texture script, `lua tests/run.lua`.

**Spec:** `docs/superpowers/specs/2026-11-17-sun-path-design.md`

## Global Constraints

- Arch: x = year fraction (0 = 1 Jan, 1 = 31 Dec); height `SunHeight(f) = 0.5 + 0.5 cos(2π(f − MIDSUMMER))`,
  `MIDSUMMER = 171/364` (21 June), so 1 at midsummer, ≈ 0 at midwinter.
- Frame: width 0.75 × minimap width, height = width × 0.25 (texture 256×64), top edge
  `PATH_GAP` = 22 px (× minimap/140) below the minimap's bottom, plus `db.arcX/arcY` nudge.
- In the texture/frame (fractions): arch runs x 0.06 → 0.94, y (from top) 0.80 at height 0 → 0.30 at height 1.
- The frame takes the mouse only for its tooltip (OnEnter/OnLeave); nothing over the minimap.
- Removed: `arc.tga`, `dot.tga`, rim arc/dot/notches. New: `sunpath.tga` (256×64), `sun.tga` (32×32).

## Review Focus

- Minimap resized: the path and its sun/notches re-laid out (Layout on OnSizeChanged).
- `/ims hide`: the path hides with the rim; `/ims arc off`: only the path hides.
- Tooltip shown from the path must hide on leave and not fight the rim watcher.
- Leap years: f stays in 0..1 on 31 December.
- Notch glow keeps pulsing (fader) for festivals on now.
